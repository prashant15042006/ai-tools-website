# Nexus AI Workspace 🚀

A premium, world-class AI dashboard featuring Chat, Code Generation, and Content Creation tools. Built with a focus on performance, aesthetics, and professional utility.

## 📂 Project Structure

- **`frontend/`**: React-based dashboard with a sophisticated, glassmorphism UI.
- **`backend/`**: Node.js/Express server integrated with Google Gemini via OpenRouter.

## 🛠️ Getting Started

### 1. Backend Setup
1. `cd backend`
2. `npm install`
3. Create a `.env` file with your `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`.
4. `npm start`

### 2. Frontend Setup
1. `cd frontend`
2. `npm install`
3. `npm start`

## ✨ Features
- **Executive Chat**: Professional, structured AI responses.
- **Advanced UI**: Large, readable fonts and modern rounded "bubble" layouts.
- **Multi-Tool**: Dedicated panels for coding and content creation.
- **Voice Support**: Integrated speech-to-text and text-to-speech.
